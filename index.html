Step-by-Step: How to Get Your Google Apps Script Web App URL

No coding experience needed—this takes about 2 minutes and only needs to be done once:

  1. Create a Google Sheet: Open sheets.google.com and click Blank spreadsheet. Name it anything you like (e.g., IsoMatch Results). Leave the cells empty—column headers will be added automatically.
  2. Open the Script Editor: In the top menu bar of your new Google Sheet, click Extensions → Apps Script. A new browser tab will open.
  3. Paste the Script Below: In the editor window, click inside the text area, select everything (Ctrl+A on Windows or Cmd+A on Mac), and press Delete so it is completely blank. Click Copy Script Code, paste it into the editor (Ctrl+V or Cmd+V), and click the Save floppy-disk icon at the top (or press Ctrl+S / Cmd+S).
  4. Deploy as a Web App:
    • Click the blue Deploy button in the top-right corner, then click New deployment.
    • Next to "Select type", click the gear icon (⚙️) and choose Web app.
    • Set Execute as to Me (your email address).
    • Set Who has access to Anyone (important: this lets players connect from their own devices without needing a Google login).
    • Click Deploy.
  5. Approve Permissions (One-Time Screen):
    • Click Authorize access and select your Google account.
    • Google will show a screen saying "Google hasn't verified this app."
      Don't worry—this is normal! Google shows this screen for every personal script you create yourself. Click Advanced (bottom-left), then click Go to Untitled project (unsafe) at the bottom, and click Allow.
  6. Copy & Test Your URL: Copy the Web app URL (starts with https://script.google.com/macros/s/ and ends with /exec), paste it into the box above, and click Test.
